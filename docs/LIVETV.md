# Free Live World IPTV for Everyone (All Countries)

CleanYourTV includes a built-in **Free Live IPTV Player &amp; Electronic Program Guide (EPG)** designed specifically for Samsung Smart TVs (Tizen OS).

It provides access to 100% free, legal, publicly available broadcast channels from every corner of the world without subscriptions, signups, dongles, or ads.

---

## What's Included

* 🌍 **All Countries:** Instant country switcher covering USA, UK, India, Canada, Australia, Germany, France, Japan, Spain, Italy, Brazil, Mexico, South Korea, and dozens more.
* 📺 **Every Major Genre:** 24/7 Live News, Live Sports, Movies, Science & Tech, Weather, Nature & Documentaries, and Entertainment.
* ⚡ **Hardware Accelerated HLS:** Streams in 1080p / 720p 60fps directly on Tizen's video pipeline using native HLS and embedded `hls.js`.
* 🎮 **Remote Control Channel Surfing:** Use your standard Samsung remote control's **Channel Up / Down** buttons (`CH ∧ / ∨`) to surf channels with zero lag.
* 📜 **Sliding EPG Guide:** Browse channels and switch countries by pressing **Left** on your remote.

## TV Remote Navigation Shortcuts

| Remote Button | Action |
|---|---|
| **`CH ∧` / Up Arrow** | Previous Channel / Surf Up |
| **`CH ∨` / Down Arrow** | Next Channel / Surf Down |
| **Left Arrow (`◄`)** | Open Sliding Channel Guide &amp; Country Selector |
| **Right Arrow (`►`)** | Switch from Country list to Channel list |
| **Enter / OK** | Select Channel / Show Info Banner (OSD) |
| **Return / Back** | Close Guide sidebar, or exit Live TV back to CleanYourTV home |

---

## How it Works

The live streaming engine is powered by the open-source community [iptv-org/iptv](https://github.com/iptv-org/iptv) database. It connects directly to the broadcaster's official public CDN streams via HTTPS HLS (`.m3u8`).
